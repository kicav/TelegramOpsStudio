# Packaging

`pysidedeploy.spec` is generated on the clean Windows build runner using `pyside6-deploy --init`,
then normalized by `scripts/configure_deploy_spec.py` to `standalone` mode. This avoids committing a
machine-specific `python_path` generated by Qt's deployment tool.

The installer (`windows_installer.iss`) is intentionally deferred until M8, after the standalone
folder has passed smoke tests on a clean Windows runner.
